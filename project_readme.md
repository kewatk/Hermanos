# Aafiya Mediretreats Webpage Clone

This project is a full front-end clone of the **Aafiya Mediretreats** website, built using **HTML**, **CSS**, and supporting assets. The goal is to recreate the layout, design, and user interface of the target webpage.

## 📁 Project Structure
```
project/
│
├── index.html
├── styles.css
├── /image
│   ├── aafiya m.png
│   ├── dr img.png
│   ├── facebook.svg
│   ├── twitter.svg
│   ├── instagram.svg
│   ├── youtube.svg
│   └── other assets...
└── /js (if applicable)
```

## 🛠️ Technologies Used
- **HTML5** – page structure
- **CSS3** – styling and layout
- **Flexbox & Grid** – responsive layout handling
- **SVG Icons** – social icons
- **(Optional) JavaScript** – interactive components (navbar, dropdowns, etc.)

## ⭐ Features Implemented
- Fully structured webpage layout
- Responsive header and navigation sections
- Social media icons aligned horizontally
- Medical treatment overview page UI
- Footer section with multiple columns
- Mobile-friendly design touches

## 🚀 How to Run Locally
1. Download or clone the project:
   ```bash
   git clone <your-repo-url>
   ```
2. Extract the folder (if downloaded as ZIP).
3. Open the project folder.
4. Double-click **index.html** to open in browser.

No server required — it runs entirely on the browser.

## 🧩 Customization
- Update images inside the `/image` folder.
- Modify colors, spacing, typography from **styles.css**.
- Add more sections or animations as needed.

## ❗ Common Issues
### 1. Images not loading
Make sure your file paths are correct:
```
/image/yourfile.png
```
### 2. CSS not linked
Check the `<link rel="stylesheet" href="styles.css">` line.

### 3. Icons not aligned horizontally
Use Flexbox:
```css
.social-icons {
  display: flex;
  gap: 10px;
}
```
